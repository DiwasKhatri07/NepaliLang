# Contributor Covenant Code of Conduct

## Our Pledge

We are committed to making participation in NepaliCode a welcoming, respectful, and harassment-free experience for everyone, regardless of background, identity, experience level, or language.

## Expected Behavior

Examples of behavior that contribute to a positive environment include:

- Showing empathy and respect toward other contributors.
- Welcoming constructive feedback and differing viewpoints.
- Using inclusive language and focusing on the work, not the person.
- Giving credit where it is due.
- Reporting concerns privately rather than escalating conflict in public threads.

## Unacceptable Behavior

Harassment, personal attacks, discrimination, intimidation, unwanted sexual attention, doxxing, trolling, and publishing someone else's private information are not acceptable. Deliberately disrupting discussions or submitting malicious code is also not acceptable.

## Enforcement Responsibilities

Project maintainers are responsible for clarifying and enforcing these standards. They may remove, edit, or reject comments, commits, issues, pull requests, and other contributions that violate this Code of Conduct.

## Reporting

Report unacceptable behavior privately to **Diwas Khatri** through [GitHub](https://github.com/DiwasKhatri) or by opening a private security report where appropriate. Please include enough context to investigate the concern. Reports will be handled as confidentially as practical.

## Scope

This Code of Conduct applies within project spaces and whenever someone is officially representing the project in public spaces.
