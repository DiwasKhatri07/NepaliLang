## 🚀 How to Use NepaliLang

### 1. **Desktop Shortcut** (Easiest)
- Look for "NepaliLang" on your desktop
- Double-click to open the CLI
- Run: `nepali.exe examples\hello.np`

### 2. **Command Line** (Any Directory)
```bash
nepali.exe yourfile.np
```

### 3. **VS Code** (Professional Development)
1. **Restart VS Code** (important!)
2. Create a new file: `test.np`
3. You should see the **NP logo** with Nepal colors
4. **Syntax highlighting** will be active
5. Press **F5** to run the file
6. See output in VS Code terminal

### 4. **Built-in Editor**
```bash
nepalicode.bat
```

## 🔧 Troubleshooting

### "nepali command not found"
- **Solution**: Restart your terminal/command prompt
- **Alternative**: Use full path to nepali.exe

### VS Code not showing NP logo
- **Solution**: Restart VS Code completely
- **Solution**: Make sure file extension is `.np`

### F5 not working in VS Code
- **Solution**: Make sure file is saved
- **Solution**: Check that file extension is `.np`

## 🎨 Features in VS Code

When you create `.np` files in VS Code after restart:

- **Syntax Highlighting** for keywords
