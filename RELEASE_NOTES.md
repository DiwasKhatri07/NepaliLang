# NepaliCode v0.1.0-alpha Release Notes

## 🎉 Initial Release - NepaliCode v0.1.0-alpha

The first public release of NepaliCode - A modern, simple programming language from Nepal!

## 📦 What's Included

### NepaliCode_Setup.exe (13.6 MB)
A complete all-in-one installer that sets up the entire NepaliCode environment:

**Features:**
- ✅ Complete language runtime (lexer, parser, interpreter, bytecode VM)
- ✅ Standard library with 10+ modules (math, time, random, JSON, file, database, HTTP, async, etc.)
- ✅ 50+ comprehensive examples
- ✅ VS Code extension integration
- ✅ Desktop shortcut creation
- ✅ System PATH configuration
- ✅ Start menu integration
- ✅ Built-in editor
- ✅ REPL (interactive shell)
- ✅ CLI tool

**Installation Options:**
- Add to System PATH
- Install VS Code extension
- Create desktop shortcut
- Add to Start menu

## 🚀 Installation

1. Download `NepaliCode_Setup.exe`
2. Run the installer
3. Select installation options
4. Click "Install NepaliCode"
5. Restart your terminal/VS Code (if PATH was modified)

## 📋 System Requirements

- **OS:** Windows 10 or later
- **Disk Space:** 50 MB for installation
- **No Python required** (self-contained)

## 🎯 Quick Start

After installation:

```bash
# Run from anywhere (if PATH added)
nepali.exe examples/01_hello_world.np

# Or use interactive REPL
nepali.exe

# Check version
nepali.exe --version
```

## 🇳🇵 NepaliCode Features

### Language Features
- **Simple Syntax:** Python-like with Nepali keywords
- **Nepali Keywords:** `yedi` (if), `kaam` (def), `firta` (return), etc.
- **Full Unicode:** Complete Nepali text support
- **Bytecode VM:** Stack-based virtual machine
- **OOP:** Classes, inheritance, methods
- **Error Handling:** Try/except with Nepali keywords
- **Module System:** Professional Python-like imports

### Standard Library
- **ganit** - Mathematics
- **samaya** - Date and time
- **randomlib** - Random numbers
- **jsonlib** - JSON operations
- **file** - File operations
- **database** - SQLite database
- **anurodh** - HTTP requests
- **asyn** - Async programming
- **system** - System operations
- And more!

### Developer Tools
- **VS Code Extension:** Syntax highlighting, run/debug integration
- **CLI:** Command-line interface
- **REPL:** Interactive shell
- **Editor:** Built-in code editor
- **50+ Examples:** Comprehensive learning resources

## 🐛 Known Limitations

This is an alpha release. Some advanced features are foundations/experimental:
- HTTP library (anurodh) - API available, needs runtime integration
- Database library - Works with SQLite
- Async programming - Foundation implemented
- Telegram/Browser automation - Foundations only
