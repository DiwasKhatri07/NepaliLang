# Installation

## Requirements

- Python 3.6 or higher
- Windows, Linux, or macOS

## Setup

1. Clone the repository:
```bash
git clone https://github.com/NepaliSource/NepaliLang.git
cd NepaliLang
```

2. Run the examples:
```bash
nepali.bat examples/hello.np
```

Or using Python directly:
```bash
python src/nepali.py examples/hello.np
```

## Running

### Run a file
```bash
nepali.bat your_program.np
```

### REPL
```bash
nepali.bat
```

### Version
```bash
nepali.bat --version
```

### Help
```bash
nepali.bat --help
```
