Standard Library

Built-in modules and functions

Available Modules

ganit - Mathematics

lyau ganit

ganit.jod(a, b)        # Addition
ganit.ghata(a, b)      # Subtraction
ganit.guna(a, b)       # Multiplication
ganit.bhag(a, b)       # Division
ganit.sqrt(x)          # Square root
ganit.power(x, y)      # Power

samaya - Date and Time

lyau samaya

samaya.abay_time()      # Current time
samaya.abay_date()      # Current date
samaya.format_time()    # Format time
samaya.add_days()       # Add days to date

randomlib - Random Numbers

lyau randomlib

randomlib.number(min, max)    # Random integer
randomlib.choice(items)        # Random choice
randomlib.shuffle(items)       # Shuffle list

jsonlib - JSON Operations

lyau jsonlib

jsonlib.parse(json_string)     # Parse JSON
jsonlib.stringify(data)        # Convert to JSON

file - File Operations

lyau file

file.read(filename)           # Read file
file.write(filename, content)  # Write file
file.exists(path)             # Check if exists
file.list_directory(path)      # List directory

database - SQLite Database

lyau database

db = database.connect("database.db")
db.execute(sql, params)
db.query(sql)
db.close()

anurodh - HTTP Requests

lyau anurodh

response = anurodh.get(url)
print(response.status)
print(response.text)
print(response.json)

asyn - Async Programming

lyau asyn

asyn kaam async_function():
    await operation()

asyn.run(async_function())

system - System Operations

lyau system

system.platform()           # Platform info
system.python_version()      # Python version
system.current_directory()   # Current directory

Note: Some modules are foundations/experimental and may require additional dependencies or updates for full functionality.
