Installation Guide

Get NepaliCode running on your system

Requirements

  • Python 3.6 or higher
  • Windows, Linux, or macOS
  • (Optional) Node.js for VS Code extension

Method 1: Using Python (Development)

# Clone the repository
git clone https://github.com/DiwasKhatri07/NepaliLang.git
cd NepaliLang

# Run an example
python main.py examples/01_hello_world.np

Method 2: Standalone Executable (Windows)

# Download nepali.exe from releases
nepali.exe examples/01_hello_world.np

Method 3: VS Code Extension

# Install from VS Code Marketplace
# Search "NepaliCode" and install

Verification

# Check version
python main.py --version

# Run REPL
python main.py

# Run example
python main.py examples/01_hello_world.np
