# First Program

## Hello World

Create a file named `hello.np`:

```np
print("Namaste Nepal")
```

Run it:
```bash
nepali.bat hello.np
```

## Variables

```np
naam = "Diwas"
umar = 20
height = 5.8
active = true

print(naam)
print(umar)
print(height)
print(active)
```

## Arithmetic

```np
print(3 + 4)
print(10 - 3)
print(5 * 6)
print(20 / 4)
```

## Conditions

```np
score = 85

if score >= 90:
    print("Grade: A")
elif score >= 80:
    print("Grade: B")
else:
    print("Grade: C")
```

## Loops

```np
for i in 5:
    print(i)
```

## Functions

```np
def add(a, b):
    return a + b

print(add(3, 4))
```

## Using Libraries

```np
import ganit

print(ganit.sqrt(25))
print(ganit.power(2, 3))
```
