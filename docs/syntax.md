# Syntax Reference

## Variables

```np
naam = "Diwas"
umar = 20
```

## Data Types

- Numbers: `42`, `3.14`
- Strings: `"Hello"`, `'World'`
- Booleans: `true`, `false`
- Lists: `[1, 2, 3]`
- Maps: `{"key": "value"}`

## Operators

### Arithmetic
- `+` Addition
- `-` Subtraction
- `*` Multiplication
- `/` Division
- `%` Modulo
- `**` Power

### Comparison
- `==` Equal
- `!=` Not equal
- `<` Less than
- `>` Greater than
- `<=` Less than or equal
- `>=` Greater than or equal

## Control Flow

### If Statements

```np
if condition:
    # code
elif condition:
    # code
else:
    # code
```

### While Loops

```np
while condition:
    # code
```

### For Loops

```np
for variable in iterable:
    # code
```

## Functions

```np
def function_name(param1, param2):
    return param1 + param2
```

## Keywords

### English
- `if`, `else`, `elif`
- `for`, `while`
- `def`, `return`
- `import`, `from`
- `try`, `except`, `finally`
- `class`
- `true`, `false`, `none`

### Nepali
- `yedi` (if), `natra` (else), `natabhaye` (elif)
- `ko_lagi` (for), `jabasamma` (while)
- `kaam` (def), `firta` (return)
- `lyau` (import), `bata` (from)
- `koshish` (try), `samau` (except), `antya` (finally)
- `kakshya` (class)
- `sacho` (true), `jhut` (false), `khali` (none)

## Built-in Functions

- `print()` - Print to console
- `len()` - Get length
- `type()` - Get type
- `str()` - Convert to string
- `int()` - Convert to integer
- `float()` - Convert to float
- `bool()` - Convert to boolean
- `list()` - Convert to list
- `range()` - Create range
- `sum()` - Sum of list
- `min()` - Minimum value
- `max()` - Maximum value
- `abs()` - Absolute value
- `round()` - Round number
